## ADDED Requirements

### Requirement: 首页信息展示
系统 SHALL 在首页展示网站 Logo、网站名称、个人简介、头像、联系方式（Github、Gitee、邮箱）、技术栈、最近项目列表、最近博客列表、AI 助手入口。

#### Scenario: 游客访问首页
- **WHEN** 游客访问首页
- **THEN** 系统展示网站 Logo、名称、个人简介、头像、联系方式、技术栈、最近项目（按置顶和时间排序）、最近博客（按发布时间排序）、AI 入口

#### Scenario: 管理员修改首页信息
- **WHEN** 管理员在后台修改网站标题、副标题、个人介绍、联系方式等信息
- **THEN** 首页实时展示最新信息

### Requirement: 首页数据接口
系统 SHALL 提供 RESTful API 获取首页所有展示数据，包括个人信息、最近项目、最近博客。

#### Scenario: 前端请求首页数据
- **WHEN** 前端调用首页数据接口
- **THEN** 返回个人信息、最近项目列表（默认5条）、最近博客列表（默认5条）

#### Scenario: 首页数据缓存
- **WHEN** 首页数据被频繁请求
- **THEN** 系统通过 Redis 缓存首页数据，数据变更时自动刷新缓存
