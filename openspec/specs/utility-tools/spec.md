## Requirements
### Requirement: 健身增肌热量计算器
系统 SHALL 提供健身增肌热量计算器：输入性别（男/女）、年龄、身高 cm、体重 kg、活动强度（久坐/轻度/中度/高强度）、目标（维持/增肌/减脂）与增肌幅度（+200/+300/+500 kcal），输出 BMR（Mifflin-St Jeor 公式）、TDEE、目标每日热量、蛋白质/碳水/脂肪克数与占比及一句解释文案。输入为空或非数字时计算按钮 MUST 禁用；结果保留整数；MUST 提供复制结果出口。

计算规则：BMR(男)=10×体重+6.25×身高−5×年龄+5；BMR(女)=10×体重+6.25×身高−5×年龄−161；TDEE=BMR×活动系数(1.2/1.375/1.55/1.725)；增肌时蛋白质 1.8g/kg、脂肪占 25% 热量、其余为碳水。

#### Scenario: 计算男性增肌热量
- **WHEN** 用户输入男、25 岁、175cm、70kg、中度活动、目标增肌 +300
- **THEN** 结果区显示 BMR、TDEE、目标热量（TDEE+300）及三大营养素克数与占比，数字为整数

#### Scenario: 非法输入禁用按钮
- **WHEN** 身高输入为空或非数字
- **THEN** 计算按钮处于禁用状态

### Requirement: 图片压缩
系统 SHALL 提供图片压缩工具：上传图片（jpg/png/webp，可多选）后拖动质量滑块（1-100），使用 Canvas 在本地压缩；输出压缩前后大小对比、压缩率、预览图与下载（多图逐张下载）。处理中 SHALL 显示进度。全程 MUST 使用本地对象 URL，图片不得离开设备。

#### Scenario: 压缩单张图片
- **WHEN** 用户上传一张 2MB 的 jpg 并以质量 80 压缩
- **THEN** 结果区显示压缩前后大小、压缩率与预览图，并提供下载按钮

#### Scenario: 多图逐张处理
- **WHEN** 用户一次上传 3 张图片
- **THEN** 工具逐张处理并显示进度，完成后每张均可单独下载

### Requirement: 格式转换
系统 SHALL 提供格式转换工具：支持图片格式互转（PNG/JPG/WebP）与 JSON↔CSV 双向转换。用户选择转换类型后上传文件或粘贴文本，转换结果提供预览与下载/复制。CSV 输出 MUST 正确转义含逗号/引号/换行的字段；JSON 输入非数组时 MUST 给出提示。

#### Scenario: JSON 数组转 CSV
- **WHEN** 用户粘贴 `[{"a":1,"b":"x"}]` 并选择 JSON→CSV
- **THEN** 结果区显示 `a,b\n1,x` 且可复制下载

#### Scenario: CSV 含特殊字符转义
- **WHEN** CSV 某字段含逗号与换行
- **THEN** 转 JSON 时该字段被正确解析为一个完整值

#### Scenario: JSON 非数组提示
- **WHEN** 用户粘贴对象 `{"a":1}` 选择 JSON→CSV
- **THEN** 结果区提示仅支持数组结构

### Requirement: JSON 格式化
系统 SHALL 提供 JSON 格式化工具：粘贴 JSON 后可执行美化（缩进 2/4/Tab 可选）、压缩与语法校验；输出格式化结果（带语法高亮）；语法错误时 MUST 显示含位置的错误信息而非崩溃；空输入时操作按钮 MUST 禁用。

#### Scenario: 美化 JSON
- **WHEN** 用户粘贴压缩 JSON 并点击美化（缩进 2）
- **THEN** 结果区显示按 2 空格缩进的高亮 JSON，可一键复制

#### Scenario: 语法错误定位
- **WHEN** 用户粘贴非法 JSON 并点击校验
- **THEN** 结果区以红色提示显示错误信息及出错位置

### Requirement: Markdown 转公众号排版
系统 SHALL 提供 Markdown 转公众号排版工具：左侧输入 Markdown，右侧实时预览公众号排版效果；支持 2-3 套排版主题与字号/行距调节；一键复制带内联样式的富文本（公众号只认内联样式）。页面 MUST 提示外链图片在公众号可能被拦截、需手动上传。

#### Scenario: 实时预览
- **WHEN** 用户在左侧输入 `# 标题\n正文`
- **THEN** 右侧即时渲染应用所选主题样式的预览

#### Scenario: 复制富文本
- **WHEN** 用户点击「复制到公众号」
- **THEN** 剪贴板写入带内联样式的富文本，粘贴到公众号编辑器保留排版；不支持的浏览器回退为复制 HTML 源码并提示

### Requirement: 随机密码生成器
系统 SHALL 提供随机密码生成器：长度 8-64 滑块可调、字符类型（大写/小写/数字/符号）可勾选、可排除易混淆字符；使用浏览器加密级随机数生成；MUST 保证每类勾选字符至少出现一个；输出密码、强度条与复制出口，支持批量生成；未勾任何字符类型时生成按钮 MUST 禁用。

#### Scenario: 生成含全部字符类的密码
- **WHEN** 用户勾选 4 类字符、长度 16，点击生成
- **THEN** 输出的 16 位密码中每类字符至少各含一个，并显示强度条

#### Scenario: 未选字符类型禁用
- **WHEN** 用户取消全部字符类型勾选
- **THEN** 生成按钮禁用

### Requirement: 颜色选择器
系统 SHALL 提供颜色选择器：通过取色控件或 HEX/RGB/HSL 任一格式输入颜色，实时显示三种格式色值（可点击复制）、明暗变体、互补色与邻近色（HSL 色轮偏移生成）。非法色值输入时 SHALL 回退到上一次有效值并提示。

#### Scenario: 多格式实时联动
- **WHEN** 用户在取色控件选择 #2563EB
- **THEN** HEX/RGB/HSL 三个输入框同步更新，点击任一色值即复制

#### Scenario: 非法色值回退
- **WHEN** 用户在 HEX 输入框键入 `xyz`
- **THEN** 输入回退为上一次有效色值并提示格式错误

### Requirement: 时间转换工具
系统 SHALL 提供时间转换工具：输入时间戳（秒/毫秒按 10/13 位自动识别）或选择日期时间，支持时区选择；输出多种日期格式、UTC 时间与相对时间，可复制。非法时间戳 MUST 提示。

#### Scenario: 毫秒时间戳转日期
- **WHEN** 用户粘贴 13 位毫秒时间戳
- **THEN** 结果区按所选时区显示完整日期、UTC 与相对时间（如「3 天前」）

#### Scenario: 非法时间戳提示
- **WHEN** 用户输入含字母的时间戳
- **THEN** 结果区提示时间戳格式非法
