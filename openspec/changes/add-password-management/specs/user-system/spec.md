## MODIFIED Requirements

### Requirement: 用户信息管理
系统 SHALL 支持用户修改个人资料（昵称、邮箱、手机、头像）和密码，支持管理员管理所有用户（含修改密码、重置密码）。

#### Scenario: 用户修改个人资料
- **WHEN** 登录用户修改自己的昵称、邮箱、手机号
- **THEN** 系统更新用户信息

#### Scenario: 用户修改头像
- **WHEN** 用户上传新头像
- **THEN** 系统将头像上传至 MinIO，更新用户头像 URL

#### Scenario: 管理员管理用户
- **WHEN** 管理员查看用户列表、修改用户状态、设置管理员角色
- **THEN** 系统执行相应操作并返回结果

#### Scenario: 管理员修改用户密码
- **WHEN** 管理员在后台用户管理中为指定用户设置新密码
- **THEN** 系统更新该用户密码，目标用户 Token 失效需重新登录

#### Scenario: 管理员重置用户密码
- **WHEN** 管理员在后台用户管理中对指定用户执行重置密码操作
- **THEN** 系统将该用户密码重置为初始密码 `33550336`，目标用户 Token 失效需重新登录
