## Why

当前全站主色硬编码为蓝色（#2563EB 及其衍生变量），单一且不可变。用户希望默认配色改为青绿色，同时配色可配置：管理员可设置站点默认配色，每个登录用户可保存自己的配色偏好（存数据库、按用户区分）。

## What Changes

- 默认主题色从蓝色改为青绿色（teal），全站按钮、链接、选中态、强调元素统一联动
- 新增预设色板：6 个精选主题（青绿 / 蔚蓝 / 紫罗兰 / 玫红 / 琥珀 / 石墨），点击即换，衍生色（hover、浅底、描边）由主色自动派生
- 新增站点默认配色：管理员在后台「系统配置」中设置，存入 sys_config，未登录及未设置偏好的用户看到该配色
- 新增用户级配色偏好：登录用户在「个人中心」选择自己的配色，存入用户数据（按用户区分），优先于站点默认
- 前端运行时换肤：通过 CSS 变量动态应用主题，切换即时生效、无需刷新页面
- Element Plus 组件主色及衍生色（light-3/5/7/8/9、dark-2）跟随主题联动

## Capabilities

### New Capabilities

- `theme-system`: 预设色板定义、站点默认配色管理、用户级配色偏好、生效优先级（用户偏好 > 站点默认 > 内置默认青绿）、前端运行时换肤与持久化

### Modified Capabilities

（无——个人中心与后台配置页仅新增一个设置入口，其行为规格并入 theme-system）

## Impact

- **数据库**：`user` 表新增 `theme` 列（VARCHAR(20)，存预设 key，NULL 表示未设置）；`sys_config` 新增 `site.theme` 配置键（无需建新表）
- **后端**：用户实体/接口带出 theme 字段；新增设置当前用户主题的接口；站点默认配色复用现有系统配置接口（getAllConfigs/setConfig）
- **前端**：style.css 中主色系静态值改为可运行时注入的 CSS 变量（衍生色用 color-mix 从主色派生）；新增主题应用模块（色板定义 + applyTheme）；Profile.vue 增加主题选择卡片；admin/Config.vue 增加站点默认配色设置
- **兼容性**：CSS `color-mix()` 需要现代浏览器（Chrome 111+ / Edge 111+ / Safari 16.2+，2023 年起全量支持），项目目标浏览器满足；不新增任何依赖
