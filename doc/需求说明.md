# 个人项目介绍网站需求文档（V1.0）

---

# 1. 项目简介

## 1.1 项目名称

AM Portal（个人展示平台）

## 1.2 项目目标

开发一个集项目展示、个人博客、AI 助手于一体的个人网站。

网站既可以作为个人主页，也可以作为个人作品集，同时提供后台管理能力，支持项目管理、博客管理、AI配置管理、用户审核等功能。

网站采用前后端分离架构，支持多环境部署，所有配置统一管理。

# 3. 系统角色

系统分为三种角色：

## 游客（Guest）

无需登录即可：

- 浏览首页
- 浏览项目列表
- 查看项目详情
- 浏览博客
- 阅读博客内容
- 使用 AI 助手（可配置是否开放）

不可：

- 修改数据
- 删除数据
- 上传图片
- 发布博客
- 新增项目

---

## 普通用户（User）

登录后：

- 修改个人资料
- 修改头像
- 使用 AI
- 收藏（预留）
- 评论（预留）

不能：

- 审核用户
- 删除他人内容
- 修改系统配置

---

## 管理员（Admin）

拥有全部权限：

- 用户审核
- 用户管理
- 项目管理
- 博客管理
- AI配置
- Prompt管理
- 系统配置
- 文件管理
- 首页信息修改

# 12. 开发原则

- RESTful API设计
- 前后端分离
- 配置集中管理
- 所有文件统一使用 MinIO
- 所有缓存统一使用 Redis
- 所有数据库统一 MySQL
- 所有 AI 能力统一由 Spring AI 管理
- 所有 Prompt 支持后台动态配置
- 所有 Function Calling 支持插件化扩展
- 所有环境统一采用 application-{env}.yml 配置
- 所有接口提供 Swagger/Knife4j 文档
- 所有模块遵循高内聚、低耦合原则
