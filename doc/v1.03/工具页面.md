## 设计原则
原则	落地方式
零后端	全部纯前端，静态托管，运行时不发任何网络请求
隐私优先	每个页面固定展示本地计算小字，图片/文本不上传
三段式一致	所有工具页统一为「介绍 → 操作 → 结果」结构，降低认知成本
结果可带走	每个工具结果区必须有复制/下载/分享至少一个出口
文案即产品	趣味工具的传播力 70% 靠文案，介绍和结果描述要反复打磨

### 信息架构
顶部导航分「工具」与「趣味」两个入口，各自进入对应导航页，再进入单个工具页。

工具导航包含 8 个实用工具：健身增肌热量计算器、图片压缩、格式转换、JSON 格式化、Markdown 转公众号排版、随机密码生成器、颜色选择器、时间转换工具。

趣味导航包含 4 个趣味工具：打字速度测试、反应力测试、MBTI 变体测试、点击计数器

每个工具拥有独立次级页面，页面标题显示工具名称。

## 实用工具页详细说明
### 健身增肌热量计算器
介绍：输入身高、体重、年龄、性别和活动量，估算维持体重和增肌所需的每日热量，并给出蛋白质、碳水、脂肪的建议摄入量。适合想科学增肌、不想盲目多吃的人。

使用方法：填写基础信息 → 选择活动强度 → 选择目标 → 点击计算。

输入：性别（男/女）、年龄、身高 cm、体重 kg、活动强度（久坐/轻度/中度/高强度）、目标（维持/增肌/减脂）、增肌幅度（+200/+300/+500 kcal）

输出：BMR（Mifflin-St Jeor）、TDEE、目标每日热量、蛋白质/碳水/脂肪克数与占比、一句解释文案

计算说明：

BMR（男）= 10×体重 + 6.25×身高 − 5×年龄 + 5

BMR（女）= 10×体重 + 6.25×身高 − 5×年龄 − 161

TDEE = BMR × 活动系数（1.2 / 1.375 / 1.55 / 1.725）

增肌：蛋白质 1.8g/kg，脂肪 25%，其余碳水

边界：输入为空或非数字时按钮禁用；结果保留整数；提供「复制结果」。


### 图片压缩
介绍：选择图片、拖动质量滑块，在本地完成压缩，原图不会离开你的设备。

使用方法：上传 → 调质量 → 预览对比 → 下载。

输入：图片上传（jpg/png/webp，可多选）、质量滑块 1-100、可选目标大小

输出：压缩前后大小对比、压缩率、预览图、下载（单张/打包）

实现：使用 Canvas 导出或现成压缩库；全程本地对象 URL；处理中显示进度。

边界：非图片文件拒绝并提示；超大图（>20MB）提示可能较慢；多图时逐张处理。


### 格式转换
介绍：支持图片格式互转（PNG/JPG/WebP）、JSON↔CSV 等常用格式转换，全部在浏览器内完成。

使用方法：选转换类型 → 上传/粘贴 → 转换 → 下载或复制。

输入：转换类型下拉（图片格式 / JSON→CSV / CSV→JSON）、文件或文本

输出：转换结果预览、下载/复制

实现：图片用 Canvas 导出；JSON↔CSV 纯 JS 递归解析；MVP 先做这两类，编码转换放 P2。

边界：CSV 含逗号/换行需正确转义；JSON 非数组时给出提示。

### JSON 格式化
介绍：粘贴 JSON 即可一键美化、压缩或校验语法错误，并定位出错位置。

使用方法：粘贴 → 选美化/压缩/校验 → 查看结果 → 复制。

输入：文本域、缩进（2/4/Tab）、操作按钮

输出：格式化 JSON（语法高亮）、错误信息（含位置）、复制

实现：解析后按缩进重新序列化；捕获错误并展示位置信息。

边界：空输入禁用按钮；错误时结果区显示红色提示而非崩溃。

### Markdown 转公众号排版
介绍：左边写 Markdown，右边实时预览公众号排版效果，一键复制带样式的富文本。

使用方法：左侧输入 → 选主题 → 复制到公众号 → 粘贴。

输入：Markdown 文本域、主题（2-3 套）、字号/行距

输出：渲染 HTML 预览、一键复制富文本

实现：Markdown 渲染 + 内联样式包装（公众号只认内联样式）；复制时写入富文本格式。

边界：图片外链在公众号可能被拦截，提示用户手动上传；超长文分段复制。


### 随机密码生成器
介绍：自定义长度和字符类型，一键生成高强度随机密码，密码只在浏览器里生成。

使用方法：拖长度 → 勾字符类型 → 生成 → 复制。

输入：长度 8-64、大写/小写/数字/符号、排除易混淆字符

输出：密码、强度条、复制、批量生成（可选）

实现：使用浏览器加密级随机数生成索引；保证每类字符至少一个；强度按长度+字符集估算。

边界：未勾任何字符类型时禁用生成；长度滑块实时显示数值。

### 颜色选择器
介绍：选择或输入颜色，实时查看 HEX、RGB、HSL 等格式，并生成协调配色。

使用方法：点色块或输入色值 → 查看格式 → 复制或看推荐配色。

输入：颜色选择器、HEX/RGB/HSL 任一输入

输出：多格式色值（可点击复制）、明暗变体、互补色/邻近色、对比度检测（可选）

实现：原生颜色控件 + 手写格式互转；配色用 HSL 色轮偏移。

边界：非法色值输入时回退到上一次有效值并提示。

### 时间转换工具
介绍：时间戳和日期互相转换，支持多时区显示和常用格式输出。

使用方法：输入时间戳或选日期 → 选时区 → 查看结果 → 复制。

输入：时间戳（秒/毫秒自动识别）或日期时间选择器、时区

输出：多种日期格式、UTC、相对时间、复制

实现：使用 Intl.DateTimeFormat 处理时区；相对时间手写。

边界：非法时间戳提示；秒/毫秒按位数判断（10 位/13 位）。

## 趣味工具页详细说明

### 打字速度测试
介绍：60 秒内打完屏幕上的文字，测出打字速度和准确率，看看能不能进排行榜。

使用方法：开始 → 照打 → 自动结算 → 查看速度 → 挑战好友。

输入：难度（英文/中文/代码）、时长（30/60/120s）

输出：WPM、CPM、准确率、错误高亮、分享卡片

实现：逐字符对比；计时用 requestAnimationFrame 或 setInterval；中文按字计。


### 反应力测试
介绍：屏幕变绿时立刻点击，测出你的反应速度。普通人约 250 毫秒，你能更快吗？

使用方法：开始 → 等变绿 → 点击 → 查看时间 → 测 5 次取平均。

输入：无（点击）、测 5 次模式

输出：单次/平均反应时间、评级（闪电级/常人级/树懒级）、分享卡片

实现：用高精度时间戳记录；随机延迟 1-4 秒防预判；提前点击判定犯规。

### MBTI 变体测试
介绍：10 道轻松小题，测出你的职场人格/社交人格变体。纯属娱乐，别太当真。

使用方法：逐题选择 → 提交 → 查看结果 → 分享。

输入：10 道单选题（每题 2-4 选项）

输出：结果类型（自定义命名）、类型描述（100 字左右）、分享卡片

实现：每题选项映射到维度加分，最后按最高分组合出类型；6-8 种结果类型。

合规：页面必须出现「娱乐向，非心理诊断」字样。

### 点击计数器
介绍：10 秒内你能点多少下？测测手速，看看能不能打破纪录。

使用方法：开始 → 疯狂点击 → 时间到看次数 → 再来或分享。

输入：无、时长（5/10/30s）

输出：点击数、CPS、评级、分享卡片

实现：点击事件累加，定时结束；移动端加触摸事件防延迟。
