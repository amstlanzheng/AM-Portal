该站为 Vue3 SPA，CSS 中主色仍是 Element Plus 默认的 #409eff，
卡片阴影/圆角/按钮全部为默认值，等于零设计。因此第一优先级是
"换掉 Element Plus 默认皮肤"，其次才是布局与排版。


========================================================
一、主提示词（完整版，推荐直接粘贴）
========================================================

你是一位擅长极简科技风的 UI 设计师兼前端工程师。请重新设计这个网站
的前端视觉，要求"简约优先，克制胜过花哨"。

【技术栈约束，必须遵守】
Vue 3 + Vite + Element Plus + Tailwind CSS。不要引入新的 UI 框架、
不要换成 React、不要重写业务逻辑。只改视觉层：样式变量、布局、间距、
排版、组件皮肤。所有改动必须能落到 CSS 变量 / Tailwind 类名 /
Element Plus 主题覆盖上。

【现有问题】
当前用的是 Element Plus 默认皮肤（主色 #409eff、默认卡片阴影、默认圆角），
元素之间缺乏视觉层级，看起来像脚手架而不是成品。

【风格定义：极简科技风 · 浅色】
关键词：留白、精确、克制、信息密度适中、工程师审美。参考气质接近
Linear / Vercel / Stripe 的浅色文档页，而不是暗黑炫酷风。

硬性要求：
1. 必须是浅色主题。禁止暗色背景、禁止"跟随系统暗色"。
2. 只允许一个强调色，建议 #2563EB（钴蓝）或 #0D9488（青）。
   强调色面积不超过整页 10%，只用于：主按钮、链接悬停、当前选中态、
   一处细节强调线。
3. 禁止：渐变背景、玻璃拟态(backdrop-blur)、霓虹发光、彩色大面积填充、
   超过 2 层的阴影、装饰性插画、彩色 emoji 图标。
4. 科技感靠这些营造（不是靠发光）：
   - 元信息（数字、编号、时间、标签）用等宽字体 ui-monospace /
     JetBrains Mono，字号比正文小 1–2px，颜色用弱灰
   - 1px 极细分割线 #E8EBF0 代替色块分区
   - 极淡点阵或网格底纹，opacity 0.03–0.05，只出现在首屏或页头，
     不做满屏
   - 精确对齐与一致间距，元素边界清晰

【设计令牌，直接采用】
- 背景：#FFFFFF 主底 / #FBFCFD 次底
- 卡片：白底 + 1px #E8EBF0 描边 + 阴影 0 1px 2px rgba(16,24,40,.04)
- 文字：主 #111827，次 #5B6472，弱 #8A93A3，禁用 #C0C4CC
- 主色：#2563EB；成功 #10B981；警告 #F59E0B；危险 #EF4444
- 圆角：卡片 10px，按钮/输入框 8px，标签 6px。禁止胶囊形和 >12px 的大圆角
- 间距：严格 8 的倍数 —— 8 / 12 / 16 / 24 / 32 / 48 / 64
- 字号：12 / 13 / 14 / 16 / 20 / 24 / 32；行高正文 1.7，标题 1.3；
  标题 600，正文 400
- 字体：Inter 或思源黑体做正文，等宽字体做数据和元信息
- 容器：max-width 1200px，左右 padding 24px（≤768px 时 16px），
  12 列栅格，列间距 24px
- 动效：150–220ms，ease-out，只动 transform 和 opacity，
  禁止弹跳、禁止旋转、禁止长动画

【Element Plus 皮肤覆盖】
- 覆盖 --el-color-primary 为上面的强调色，并同步生成 3/5/7/8/9 深浅档
- 卡片 el-card：去阴影，改 1px 描边，圆角 10px，header 底部分割线
- 按钮：默认尺寸改 32px 高，圆角 8px；主按钮实心，次按钮白底描边，
  禁止阴影
- 输入框/选择器：高度 32px，描边 #E1E5EB，聚焦时描边变强调色 +
  2px 外发光环 rgba(37,99,235,.12)
- 标签 el-tag：改描边样式（浅灰底 + 1px 边），禁止彩色实心标签
- 表格：去斑马纹，表头浅灰 #F7F8FA，行高 48px，只有横向分割线
- 弹窗/抽屉：圆角 12px，遮罩 rgba(17,24,39,.32)，去掉边框

【页面结构要求】
- 顶部导航：高 56px，白底，底部 1px 分割线，左侧 logo 文字 600 字重，
  右侧导航项 14px 次色，悬停变主文字色，当前项下方 2px 强调色短线
  （不用背景块）
- 首屏：左侧标题 + 一句话说明（最多两行），右侧或下方是内容区；
  不要大 banner、不要轮播
- 内容卡片：统一高度对齐，封面图统一 16:9 或者干脆去掉封面改用文字型
  卡片；标题 16px/600，描述 13px 次色，最多两行截断
- 卡片悬停：描边变 #D3D9E3 + 阴影提升到 0 4px 12px rgba(16,24,40,.06)
  + 上移 2px，200ms
- 空状态、加载态：用细线骨架屏，不要转圈 spinner

【交付方式】
请分三步输出，不要一次性给完整代码：
第一步：给出改造方案说明 + 完整设计令牌（CSS 变量清单）
第二步：给出全局样式文件（variables.css / 主题覆盖）和布局骨架代码
第三步：给出 2–3 个核心组件（导航、卡片、按钮组）的完整实现
每一步等我确认后再继续。

【自检清单，输出前逐条确认】
浅色底是否贯彻？强调色是否只有一个且用得克制？是否没有任何渐变和发光？
所有间距是否都是 8 的倍数？字号种类是否控制在 6 个以内？
灰色是否有明确的三级层次？去掉所有颜色后，页面靠间距和排版是否依然
清楚可读？
